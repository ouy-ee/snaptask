# 验证清单(重要)

> 本次开发会话的权限模式禁止执行命令,**代码未经本机运行验证**。
> 请按以下顺序在你的机器上验证,任何一步失败请把报错发回来,我会立即修复。

## 1. 后端安装与测试(~3 分钟)

```bash
cd server
npm install          # 需要 Node ≥ 20;better-sqlite3 会自动下载 Windows 预编译二进制
npm test             # 应全部通过(认证/文件夹/记录/上传/待办/分析/归一化)
npm run dev          # 应输出 "snaptask-server 已启动"
# 另开终端验证健康检查:
curl `http://localhost:8787/api/health`
# 应返回 {"ok":true,"service":"snaptask-server",...}
```

## 2. 前端安装与测试(~3 分钟)

```bash
npm install
npm test             # client / store reducer / LoginPage 测试应通过
npm run dev          # http://localhost:5173
```

## 3. 云端模式功能走查(后端在线时,~10 分钟)

1. 打开 `http://localhost:5173` → 自动进入**登录页**(说明已探测到后端)。
2. 注册新账号 → 进入首页;顶部导航出现「云端」徽标,账号菜单显示你的邮箱。
3. 上传 2~3 张截图 → 工作区(「模拟场景」下拉应已消失)。
4. 点击开始分析 → 正常进入五阶段流程并产出结果(后端现在要求必须配置 VISION_API_KEY,未配置会**拒绝启动**;想验证失败/重试路径,可临时把 Key 改成一个无效值再试,确认失败页与「重试」「返回工作区」正常,然后改回)。
5. 首页新建/重命名/删除文件夹;结果页保存结果 → 历史记录出现、文件夹计数正确。
6. 记录移动、移入回收站、恢复、彻底删除。
7. 结果页「同步到首页」→ 待办出现在首页,勾选完成。
8. 结果页导出并归档 → 首页归档面板出现 TXT,点击预览/下载。
9. 开两个标签页:一个标签页删除记录 → 另一个标签页几秒内列表刷新(多标签同步)。
10. 停止后端(`Ctrl+C`)→ 刷新页面 → 自动回退**本地 Demo 模式**(导航显示「Demo」),旧功能全部可用;重启后端刷新 → 回到云端模式。
11. 退出登录 → 跳登录页;重新登录数据仍在。

## 4. 真实 AI 分析(需要免费 API Key,~10 分钟)

1. 到 [智谱开放平台](https://open.bigmodel.cn/) 注册,创建 API Key(默认模型 GLM-4V-Flash,收费状态以官网为准,见 docs/COSTS.md)。
2. `server/.env` 中填 `VISION_API_KEY=<你的Key>`,重启后端。
3. 上传截图 → 开始分析 → 观察五阶段进度 → 结果页检查:总结/事实/任务/对比表/警告,来源标记点击能打开图幅。
4. 断网或填错 Key 再试一次 → 失败页文案应显示对应错误,可重试。
5. (可选)OCR:按 `server/ocr/` 的 README 启动 PaddleOCR(免费),`.env` 设 `OCR_PROVIDER=paddle` → 重新分析后,结果页来源定位框应高亮真实文字区域。

## 5. 生产部署验证(见 docs/DEPLOY.md)

- `server/docker-compose.yml` 起服务 → 健康检查通过。
- nginx 配置启用后:`curl -I https://你的域名` 应含 CSP / nosniff 头;HTTP 自动跳 HTTPS。
- 提交代码前:确认 `.env` 未入库(`git status` 无 server/.env)。

## 5. 产品化功能走查(2026-11-17 新增)

1. **账号设置**(右上角头像 → 账号设置,或直接访问 /settings):改称呼、改密码(提交后其他设备退出)、导出全部数据(JSON 下载)、注销账号(双重确认,数据彻底清除);
2. **记录抽屉增强**:排序(最新/最早)、文件夹筛选下拉、「☑ 批量操作」→ 勾选多条 → 批量移动/批量删除(单次确认);
3. **文件夹树拖拽**:按住一条记录拖到其他文件夹节点上(虚线高亮)→ 松手即移动;
4. **归档悬浮操作区**:鼠标悬浮归档行显示操作按钮;预览=图片弹窗/文本卡片/其他类型触发下载(带 Token 的 Blob 方案)。

## 已知边界(设计取舍,非缺陷)

| 项 | 说明 |
| --- | --- |
| 服务端缩略图 | 采用**客户端上传前压缩**(免费、零原生依赖)替代;服务端 sharp 缩略图列为后续可选优化(见 ROADMAP) |
| 分析取消 | 视觉调用本身不可中断,取消在调用返回后立即生效(状态正确,最多多等一个模型调用) |
| 恢复「上次保存的结果」 | 云端模式读的是本地缓存快照;如需云端权威版本请从历史记录打开 |
| 邮箱验证/找回密码 | 未纳入本期(避免邮件服务依赖与成本);密码修改与注销已支持 |
| TypeScript 迁移 | 提供 `src/types/domain.d.ts` 类型声明;`.jsx → .tsx` 全量迁移在路线图 P2 |
| 数据导出范围 | 结构化数据(记录含 result、文件夹、待办、归档元信息),不含原图二进制;导入与批量服务端接口在路线图 |
| 视觉回归/浏览器兼容矩阵 | 需在真实浏览器手工走查;CI 已含单测+构建 |
| 批量操作 | 当前为前端串行调用现有接口;量大时建议服务端批量接口(路线图 P2) |
