# 成本方案:免费优先 + 最便宜付费兜底

> ⚠️ **重要声明**：撰写本文档时本会话**无法联网核实价格**。表中所有"价格/免费额度"均为撰写时的公开信息快照，**部署前必须点击对应的官方价格页重新确认**（链接已附）。若某免费方案已改为收费，请按"最便宜付费方案"列评估，或换用表内其他免费方案。

## 总原则

| 原则 | 说明 |
| --- | --- |
| 免费优先 | 每项能力先提供免费方案，且**已实现为可配置的 Provider 适配层**（换供应商只改环境变量，不改代码） |
| 自托管兜底 | 免费云额度可能缩水，因此关键路径（OCR、视觉模型、存储、数据库）全部支持自托管开源替代 |
| 防超支保护 | 服务端内置**每日调用配额**（`OCR_DAILY_LIMIT` / `VISION_DAILY_LIMIT`），达到阈值即拒绝调用，避免供应商改价后产生意外账单 |

## 推荐起步组合（全免费）

```
视觉模型  = 智谱 GLM-4V-Flash（¥0,需到官网确认仍免费）
OCR      = PaddleOCR 自托管(¥0)  或 百度 OCR 免费额度(每月1000次)
存储     = 本地磁盘(¥0),有量后迁 Cloudflare R2 免费档(10GB)
数据库   = SQLite(¥0)
主机     = 自有机器(¥0)
HTTPS    = Let's Encrypt(¥0)
```

**合计：¥0/月**（除域名约 ¥30~60/年，可选）。

若后续 GLM-4V-Flash 收费：按 1000 次分析/月、每次约 3 张图、每张图约 1500 输入 tokens 估算，视觉模型成本约 ¥5~15/月量级（按 ¥8/百万 tokens 快照价粗算），仍是个人可接受范围。精确数字以部署时官方价格页为准。
