# SnapTask 使用指南(用户版)

> 写给第一次访问 SnapTask 的你。读完这份指南,5 分钟即可完成第一次「截图 → 分析 → 结果」的全流程。

## SnapTask 是什么

SnapTask(截图任务助手)把**一张或多张截图**变成:

- **AI 总结** —— 一句话说清截图内容
- **核心知识点** —— 截图里的关键信息,逐条提取
- **待办事项** —— 从内容里识别出的任务清单,可同步到首页跟踪
- **对比表格** —— 多张截图之间的异同,自动排成表格
- **冲突与警告** —— 截图之间说法不一致的地方,明确标出,**绝不假装没有冲突**

它最特别的一点是**来源追溯**:结果里的每一条结论,都标注了来自哪张截图(用图例色标 ①②③ 表示)。点击标记,就能打开原图并看到高亮的具体位置 —— 结论从哪来,一眼可查。

## 快速上手(5 步)

1. **注册账号**:打开网站 → 切换到「注册」→ 填写称呼、邮箱、密码(至少 8 位)→ 注册成功自动登录。
2. **上传截图**:首页点击上传面板,或把截图直接拖进去。支持 PNG / JPG / WEBP,单张不超过 10MB,一次最多 6 张。
3. **进入工作区**:上传后自动进入截图工作区,可调整图幅顺序、删减或替换截图。
4. **开始分析**:点击「开始分析」,观察五阶段进度(读取图幅 → 识别注记 → 拼合图景 → 校勘比对 → 成图),云端 AI 一般 15~90 秒完成。
5. **查看并保存结果**:结果页查看总结、知识点、待办、对比表和警告;点击「保存」存入历史记录,之后可随时从首页历史记录打开。

## 页面与功能详解

### 首页

- **上传面板**:点击或拖拽上传截图;面板下方会说明当前数据处理方式。
- **历史记录**(右侧):所有保存过的分析结果,支持排序、按文件夹筛选、批量移动/删除,以及拖拽记录到文件夹;删除的记录先进入**回收站**,可恢复或彻底删除。
- **紧急待办**(右侧):显示从分析结果同步过来的任务,勾选即完成。
- **归档文件**(右侧):导出的 TXT 等文件,支持预览、下载、重命名、删除。

### 截图工作区

- **左侧图幅队列**:每张截图一个图例色标(①②③…),可拖拽调整顺序、删除;某张截图不理想,点开大图后可以「替换此图」。
- **中间大图预览**:查看当前选中的截图。
- **右侧信息区**:显示图幅数量、每张图的质量评分(清晰/一般/较低)与预计耗时,然后点击「开始分析」。
- 分析过程中可以随时**暂停/继续**,或**取消并返回工作区**;分析失败会给出原因,可直接**重试**。

### 结果页

结果页是核心,自上而下依次是:

| 区块 | 内容 |
| --- | --- |
| AI 总结 | 一段话概括全部截图的内容 |
| 核心知识点 | 逐条提取的关键信息 |
| 待办事项 | 识别出的任务;可编辑、勾选,并「同步到首页」跟踪 |
| 对比表格 | 多张截图的关键字段横向对比 |
| 风险警告 | 冲突、缺失、不确定的内容,明确标红提示 |

- **来源追溯**:每一条结论后面都有图例色标,点击即可打开来源图幅,高亮显示 AI 识别标注的具体区域。
- **编辑与修改**:结论可编辑;支持撤销/恢复;修改后点「保存」(或按 Ctrl+S)。
- **顶部操作栏**:导出(可选格式)、保存至文件夹、返回首页。
- **图幅变了怎么办**:左下角可添加新截图、替换或删除现有截图、从历史图库补充;图片变动后应用会询问是否立即重新分析。

### 账号设置(右上角头像 → 账号设置)

- 修改称呼
- 修改密码(提交后其他设备会退出登录)
- 导出全部数据(JSON 文件下载,包含记录、文件夹、待办等)
- 注销账号(**彻底删除**所有数据,需两次确认,不可恢复)

## 隐私与数据安全

- 截图经 HTTPS 加密上传,存储在你的**私有账号**下,**仅你本人可见**。
- 分析完成后,结果保存在你的账号里;可随时删除记录,或注销账号彻底清除。
- 请勿上传高度敏感信息;分析由云端 AI 服务完成,请选择你信任的服务使用。
- 分析结果里的每一条结论都标注来源,不确定和冲突的内容会被明确提示,不会伪装成事实。

## 常见问题

**为什么有时候打开网站没有登录页,界面还写着「Demo」?**

当云端服务不可用(维护、网络波动等)时,网站会自动回退到本地演示模式,让你依然可以体验完整流程。演示模式下的数据保存在你的浏览器本地,与云端账号**互不相通**;服务恢复后刷新页面即可回到云端模式。

**数据存在哪里?会丢吗?**

云端模式:数据存在你的账号下,多设备登录同一账号即可看到;两个标签页同时打开会自动同步。演示模式:只存在当前浏览器里,清除浏览器数据会丢失。

**忘记密码怎么办?**

目前暂不支持邮箱找回(注册邮箱仅作账号标识,不会收到邮件)。请务必保管好密码;已登录状态下可以在「账号设置」中修改密码。

**支持哪些浏览器?**

推荐使用最新版的 Chrome、Edge、Firefox 等现代浏览器。
